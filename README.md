# communication-stability-ml
#SUMO and ns-3 simulation files for communication stability prediction using machine learning.I have uploaded important files from SUMO and NS-3 simulations.
## Overview

This repository contains the SUMO, ns-3, machine learning code, and dataset used in the research study on intelligent vehicular communication and network performance enhancement.

## Software

* SUMO 1.12.0
* ns-3.27
* Python
* OpenStreetMap

## Repository Contents

* **SUMO/** – SUMO configuration, network, and route files
* **ns-3/** – ns-3 vehicular communication simulation code
* **ML/** – Machine learning implementation
* **dataset/** – Dataset generated from the simulation

## Workflow

SUMO → Vehicle Mobility → ns-3 → Network Metrics → Dataset → Machine Learning

## Purpose

The repository is provided for research reproducibility and further study of machine learning-based vehicular communication.
